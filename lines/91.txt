 وَالشَّمْسِ وَضُحَىهَا ( 1 ) وَالْقَمَرِ إِذَا تَلَىهَا ( 2 ) وَالنَّهَارِ إِذَا جَلَّىهَا ( 3 )
 وَالَّيْلِ إِذَا يَغْشَىهَا ( 4 ) وَالسَّمَاءِ وَمَا بَنَىهَا ( 5 ) وَالْأَرْضِ
 وَمَا طَحَىهَا ( 6 ) وَنَفْسٍ وَمَا سَوَّىهَا ( 7 ) فَأَلْهَمَهَا فُجُورَهَا
 وَتَقْوَىهَا ( 8 ) قَدْ أَفْلَحَ مَن زَكَّىهَا ( 9 ) وَقَدْ خَابَ مَن دَسَّىهَا ( 10 )
 كَذَّبَتْ ثَمُودُ بِطَغْوَىهَا ( 11 ) إِذِ انبَعَثَ أَشْقَىهَا ( 12 ) فَقَالَ لَهُمْ
 رَسُولُ اللَّهِ نَاقَةَ اللَّهِ وَسُقْيَاهَا ( 13 ) فَكَذَّبُوهُ فَعَقَرُوهَا فَدَمْدَمَ
 عَلَيْهِمْ رَبُّهُم بِذَنبِهِمْ فَسَوَّىهَا ( 14 ) وَلَا يَخَافُ عُقْبَاهَا ( 15 )
